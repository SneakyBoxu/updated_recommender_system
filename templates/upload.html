How to get MovieLens

Step 1
1
Download the dataset
Go to grouplens.org/datasets/movielens and download ml-latest-small.zip (100 k ratings, ~1 MB) or ml-latest.zip (full dataset, ~300 MB).
2
Extract the ZIP
Unzip it. You will find ratings.csv and movies.csv inside the folder.
3
Upload below
Drag & drop (or browse) the two files into the upload zones below, then click Load into MineMatrix.

Alternative: Manual File Placement

Advanced

Instead of uploading, you can place the files directly in the project folder and restart the app: 

MineMatrix/
  kaggle_data/          ← create this folder
    ratings.csv         ← put ratings.csv here
    movies.csv          ← put movies.csv here (optional)

Then restart python app.py — it will auto-detect the files on startup.
