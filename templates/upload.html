How to Load Your Data

Step 1
1
Prepare your CSV file
Your ratings CSV must contain at least 3 columns: user ID, item ID, and rating. Column names can be anything (e.g., userId/movieId/rating, student/course/score, etc.)
2
Optional: Item metadata
You can also upload an items CSV with additional information (e.g., titles, genres, descriptions). This file should have an item ID column matching your ratings file.
3
Upload and map columns
Upload your file(s) below. The system will auto-detect columns, but you can manually select the correct ones if needed.
Example: MovieLens Dataset

Want to try with real data? Download the MovieLens dataset from grouplens.org/datasets/movielens. Get ml-latest-small.zip (100k ratings, ~1 MB) or ml-latest.zip (full dataset).

Extract the ZIP and upload ratings.csv and optionally movies.csv.

Alternative: Manual File Placement

Advanced

Instead of uploading, you can place the files directly in the project folder and restart the app: 

MineMatrix/
  kaggle_data/          ← create this folder
    ratings.csv         ← put ratings.csv here
    movies.csv          ← put movies.csv here (optional)

Then restart python app.py — it will auto-detect the files on startup.
